# JS 还原（内置 jsrestore）

> 把**混淆过的 JS** 还原成可读代码，或只做**格式化美化**。
> 入口：工具箱 → **JS 还原**（查看类）；文本编辑器里选 `JavaScript` 语言也可直接格式化。

---

## 1. 是什么

应用内置了两个成熟的 JS 处理引擎（都以 assets 打包、用内置 JS 运行时执行）：

| 能力 | 引擎 | 说明 |
|---|---|---|
| **反混淆 / 反编译** | acorn + jsrestore | 8 步流水线，见下 |
| **格式化美化** | js-beautify | 只排版、不改语义、保留注释 |

两个能力都在**本机离线**运行：不联网、不上传代码、也不执行被分析的代码
（只有「语法验证」会在桩环境里尝试加载，用假 DOM 顶替浏览器 API）。

---

## 2. 反混淆流水线（8 步）

1. **文本清理** —— 去掉不影响语义的噪音
2. **字符串表解密** —— 还原 `["\x48\x65..."]` 这类字符串数组与取值函数
3. **Helper 池内联** —— 内联混淆器生成的公共辅助函数
4. **控制流平坦化** —— 还原 switch-dispatch 式扁平化
5. **常量折叠 / 死代码消除** —— `1+2*3 → 7`、`if(1===1)` 展平
6. **死对象清理** —— 删除不再被引用的对象 / 函数
7. **语法修复** —— 补齐括号分号；产物保证语法合法
8. **语义命名** —— 按调用上下文恢复 `_0x1a2b` 这类标识符

每一步都会打印体积变化，方便判断哪一步起了作用。

---

## 3. 使用方法

1. 打开工具箱 → **JS 还原**；
2. 把混淆的 JS 贴进输入框（或点「粘贴」「选择文件」）；
3. 选一个动作：

| 按钮 | 作用 |
|---|---|
| **一键还原** | 跑完整流水线，输出可读代码 |
| **格式化** | 只做排版美化（保留注释，不做任何反混淆） |
| **识别指纹** | 判断混淆类型与置信度，给出推荐流水线 |
| **语法验证** | 检查语法是否合法、能否在桩环境加载 |

4. 结果区可**选中复制**，或用右上角按钮**复制 / 保存为文件**（`*.restored.js`）；
5. 「过程日志」可展开查看每一步的体积变化。

> 输入上限 2 MB（超出会被拒绝，避免长时间占用 JS 引擎）。

---

## 4. 文本编辑器里的 JS 格式化

工具箱 → **文本编辑器**，把语言选成 `JavaScript`（或打开 `.js` 文件自动识别），
右上角的「格式化」按钮就会生效 —— 底层调用同一套 js-beautify。

目前支持格式化的语言：**JSON / XML / HTML / CSS / JavaScript**。

## 5. 实现细节（开发）

### 5.1 引擎装载（`lib/network/util/js_deobfuscator.dart`）

Node 版 jsrestore 只依赖 `fs` / `path` / `acorn` 三个模块和
`process.argv` / `process.exit` / `console`，因此**不改它的源码**，
而是用 **CommonJS 包装 + 桩模块** 直接在 JS 引擎里跑：

- `fs` 桩：读文件 → 读内存里传入的字符串；写文件 → 被捕获为输出；
- `process` 桩：注入 argv；`exit` 只记录退出码（不终止引擎）；
- `console` 桩：把过程输出收集成日志返回 UI。

按需加载：只有用到对应能力时才装载模块（jsrestore 约 300KB / js-beautify 约 150KB）。

### 5.2 资源

| 文件 | 用途 |
|---|---|
| `assets/js/acorn.js` | JS 解析器（UMD） |
| `assets/js/jsrestore.js` | 反混淆流水线（Node 版原样） |
| `assets/js/js-beautify.js` | 格式化（UMD） |

### 5.3 API

```dart
// 反混淆 / 指纹 / 验证
final r = await JsDeobfuscator.run('restore', code);
// r.ok / r.output / r.logs

// 纯格式化
final pretty = await JsDeobfuscator.beautify(code);
```

## 6. 与其他功能联动

- **抓包定位**：先用 ProxyPin 抓到带 `sign` / `timestamp` 的接口，再找对应 JS 还原；
- **脚本复现**：读懂签名算法后，在「脚本」里用 JS 复现（脚本引擎提供 `md5`、`fetch`、`require(url)`）；
- **自动补参**：用「请求重写」或脚本自动补上签名，方便反复调试；
- **安全自检**：还原后的代码也可粘进「安全自检」的自定义规则里做关键词扫描。

> 只对你自己的应用或**已获授权**的目标做这类分析。

## 7. FAQ

**Q：会上传我的代码吗？**
A：不会。引擎与资源都在本地，全程无网络请求。

**Q：会不会执行我贴进来的代码？**
A：反混淆与格式化都不会执行它；只有「语法验证」会在桩环境（假 DOM / 假 fetch）里尝试加载。

**Q：支持 TypeScript / 现代语法吗？**
A：acorn 按最新 ECMAScript 解析；TS 专有语法（类型注解等）不在范围内。

**Q：为什么输入要限 2 MB？**
A：JS 引擎是同步执行的，超大文件会长时间占用导致界面卡顿，因此设了上限。
