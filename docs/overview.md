# 功能总览

> ProxyPin 全部功能的入口、用法与文档索引。重点标记说明见文末。

## 抓包核心

| 功能 | 入口 | 说明 | 详细文档 |
|---|---|---|---|
| HTTP(S) 抓包 | 启动即用 | ==先安装 CA 证书再开启抓包== | 证书与 HTTPS 抓包 |
| WebSocket 抓包 | 工具箱 → WebSocket | WS/WSS 消息实时查看 | — |
| 系统代理 | 设置 → 开启抓包 | 桌面端一键接管系统代理 | — |
| VPN 模式 | Android 启动抓包 | 无需 WiFi 代理配置 | — |
| 远程设备 | 设置 → 远程设备 | 手机抓包转发到电脑分析 | 常用功能技巧 |
| URL 编码/中文域名 | 自动 | ==含 % 的 URL 编码主机名不再报 FormatException==，自动解码 + Punycode 解析（上游 #923） | 常用功能技巧 |
| QUIC 拦截 | 偏好设置 → 自动开启抓包下方 | ==丢弃 UDP:443 强制回落 TCP==，游戏类 App 也能抓 | 常用功能技巧 |
| 双向认证 mTLS | 偏好设置 | 上游要求客户端证书时配置 | 常用功能技巧 |

## 自动化与 AI

| 功能 | 入口 | 说明 |
|---|---|---|
| MCP Server | 设置 → MCP Connection | AI 客户端经 SSE/Streamable HTTP 接入 |

| 定时任务 | MCP Connection → 自动化 | ==一次性/每天/每周/间隔/Cron 五种模式== |
| 事件监听 | MCP Connection → 自动化 | onRequest/onResponse/启停触发 |
| 规则引擎 | MCP Connection → 自动化 | 条件匹配 → 动作（改包/拦截/通知） |
| Prompts/Roots | MCP Connection → 自动化 | MCP 提示模板与资源根 |
| 工作流 | MCP Connection → 工作流 | 多步骤编排执行 |
| AI 分析 | 设置 → MCP Connection → AI 分析 | ==对话式 AI 分析==，附件多类型多选 |
| Agent 模式 | AI 分析页 🤖 开关 | ==AI 自动调用 ProxyPin 工具==（轮数/附加指令可自定义） |
| 悬浮球 | MCP Connection → 悬浮球 | ==36dp 液态玻璃正圆球==（径向渐变+高光+波纹，无描边，支持拖动/贴边收纳/冷启动自动恢复）；==先在「悬浮球权限」入口授权==；点击在==球旁弹出配置面板==（MCP 设置/换颜色/调透明度/贴边开关/关闭），配置实时同步设置页 |
| Shizuku / Dhizuku | MCP Connection → 设备状态 | 免 root 执行自动化 Shell；==需 Shizuku 应用处于运行状态==，状态显示 已授权/未授权/未连接 三态，「请求 Shizuku 授权」按钮在未授权时显示，点击后在应用内弹出系统授权弹窗 |

## 个性化

- 主题色 / 莫奈取色（Android 12+）/ 深浅模式：设置 → 偏好设置
- 预测性返回：偏好设置（Android 14+ 预测返回手势动画）
- 启动页：偏好设置 → 启动页。==原启动页==为主题色背景 + 图标放大动画（==图标随主题色/莫奈取色染色==）；另有渐变品牌页 / 自定义图片 / 透明可选，时长 0.2~5 秒连续可调，支持自定义小字。冷启动完整链路：系统启动画面（应用图标 + 主题色背景，随系统深浅模式）→ 原启动页（背景与图标即时跟随应用主题）→ 主界面，无缝衔接
- 搜索历史：搜索条件面板顶部最近 8 条关键词
- ==下拉长文本不再截断==：选项名较长时（如「请求 Content-Type」）单行显示 + 省略号，长按/悬停查看完整文本；规则引擎、搜索条件面板等处一致（上游体验修复）
- 请求列表选中以请求 ID 记录：新请求涌入时当前选中行高亮不丢失
