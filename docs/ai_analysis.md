# AI 分析使用指南

AI 分析可以把抓包数据交给大语言模型解读：接口用途、字段说明、异常与风险提示，并支持多轮追问。基于 OpenAI 兼容接口，支持 OpenAI / DeepSeek / 通义千问 / 本地 Ollama 等任何兼容服务。

## 入口

- 「设置 → MCP Connection → AI 分析」打开对话页；
- 请求长按菜单（移动端）/ 右键菜单（桌面）「AI 分析」：直接进入对话页并自动附加该请求；
- 工具箱「使用文档 → AI 分析使用指南」查看本文档。

## 首次配置

1. 进入对话页，点击右上角 ⚙ 打开配置；
2. 打开「启用 AI 分析」；
3. 从 ==服务商列表== 选择（OpenAI / DeepSeek / 通义千问 / Kimi / 智谱 / Ollama 本地），选中的服务商自动填好接口地址与模型建议；或选「自定义服务…」手动填写 OpenAI 兼容地址；
4. 填写 API Key、模型名；
5. 支持 __从文件导入配置__：JSON 格式 `{"baseUrl": "...", "apiKey": "...", "model": "...", "enabled": true}`；
6. 保存后即可使用。Key 保存在本机配置中，不会上传到 ProxyPin 之外的任何地方。

==接口地址支持两种填法==（自动识别，不会重复拼接）：

- Base URL 形式：`https://hmai.n10.top/v1`（程序自动补 `/chat/completions`）
- 完整接口形式：`https://hmai.n10.top/v1/chat/completions`

自建网关（OneAPI/NewAPI 等）与各类代理服务均可直接填写。

## 附加上下文（可多类型多选）

点击右上角 📎 附加信息，三种类型可同时附加多条：

| 类型 | 说明 |
|---|---|
| 抓包请求 | 从最近 30 条中**多选**，自动附带完整请求头/体与响应 |
| API 端点清单 | 自动提取全部端点（方法/域名/路径/调用量/耗时/成功率） |
| 自定义文本 | 粘贴任意内容（日志、需求说明、代码片段等）作为上下文 |

发送后附件以 📎/📊/📝 标签显示在气泡中，可单独移除。

## Agent 模式（AI 自动调用 ProxyPin 功能）

点击右上角 🤖 开关：

- **开启**：AI 可以自动调用 ProxyPin 内置工具（查看最近请求、请求详情、API 端点、修改系统代理配置等）。AI 判断需要数据时自动执行，结果回喂后继续回答，你只需要提问（如"最近哪个接口最慢？""帮我看看有没有异常请求"）；
- **关闭**：AI 仅接收你手动发送的消息与附件，不会自动读取应用数据（更省 Token、更隐私）。

Agent 模式单次问答自动执行的轮数可在 __AI 配置 → Agent 模式__ 中自定义（1~8 轮），并支持填写 ==Agent 附加指令==（如"优先检查安全风险""只看 POST 请求"），作为系统指令注入；每次调用在气泡中显示「已调用工具 xxx」。

## 多轮对话

对话支持连续追问，AI 记住上文：

```
你：分析附加的这条请求
AI：（输出接口用途/要点/风险）
你：它的响应慢在哪里？
AI：结合之前的请求耗时分析…
```

AI 回复支持长按/点击复制。

## 多会话管理（互不干扰的分析线）

- 右上角 **对话列表**（AppBar 左侧图标）：新建 / 切换 / 删除会话；首条消息发送后自动以消息摘要命名，便于日后区分
- 「**清除当前对话**」：一键清空当前会话上下文重新开始，不删除会话记录
- 适用：同时对比分析多个接口/多批请求时各开一路会话，互不串上下文

## 隐私与安全

- 附加的请求内容（含 Header、Body）会发送给你配置的 AI 服务，注意不要附加含敏感凭证的请求；
- Agent 模式下 AI 只能通过白名单工具查看数据与少量配置，无法删除数据或执行脚本；
- 建议在生产环境中关闭 Agent 模式或使用内网部署的模型。

## 开发说明

- AI 服务调用：`lib/network/components/ai_analyzer.dart`（OpenAI 兼容 chat/completions）；
- 对话页：`lib/ui/component/ai_analysis.dart`（消息气泡、附件、Agent 循环）；
- Agent 工具协议：`<tool>{"name":"...","arguments":{...}}</tool>` 文本协议，经 `McpServer().executeTool()` 执行，与 MCP Server 的工具完全同源；
- 配置字段：`AppConfiguration.aiEnabled / aiBaseUrl / aiApiKey / aiModel / aiAgentEnabled`。
